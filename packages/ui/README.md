# @trackecom/ui

Design system for TrackEcom (React components and design tokens, RTL first). Owned by Abdennour; built in #14. Brand colours are in [BRAND.md](../../BRAND.md).

Import `@trackecom/ui/styles.css` once in the app root, then import primitives and domain controls from `@trackecom/ui`.

The `tailwind.preset` export shares TrackEcom colors, fonts, radii and elevation with Tailwind 3 projects. Storybook exposes language, direction and theme controls so every story can be reviewed in Arabic RTL, French and English, in light and dark themes.
